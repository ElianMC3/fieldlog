      Cómo usar FieldLog

      1. Registrar un trabajo (Bitácora)

      Estás en la pestaña Bitácora. Toca el botón + (esquina inferior derecha), elige el tipo de trabajo, escribe la ubicación y las notas, y toca ✔. El registro aparece en la lista con el estado pendiente.

      2. Controlar el Inventario

      Cambia a la pestaña Inventario y toca + para dar de alta artículos con clave, nombre, cantidad y unidad. Funciona igual: se guarda primero en el dispositivo.

      3. Trabajar sin conexión

      Puedes usar la app con el modo avión activado. La barra verde/roja bajo el título te dice si estás En línea o Sin conexión y cuántos registros faltan por enviar. Todo se guarda en el dispositivo (IndexedDB): nada se pierde si cierras la app o se apaga el equipo.

      4. Sincronizar

      Al volver la red, la app envía sola los registros pendientes. También puedes forzarlo tocando el icono ⟳ del título. Cuando termina, el badge cambia a sincronizado y recibes una notificación con el resultado.

      5. Activar las notificaciones

      Toca la campana 🔔 del título y acepta el permiso. Eso suscribe el dispositivo al servidor de notificaciones configurado (ver sección 7). La campana se enciende en amarillo cuando ya está activa; vuelve a tocarla para desactivarla.

      Si la bloqueaste antes: borra el sitio en Configuración → Privacidad → Sitios → Notificaciones y recarga la página.

      6. Instalar como app

      Android/Chrome: menú ⋮ → Instalar aplicación o Añadir a pantalla de inicio. iPhone/Safari: botón Compartir → Añadir a pantalla de inicio. Escritorio: ícono de instalar en la barra de direcciones.

      7. Configurar el servidor

      Escribe la URL pública del servidor de notificaciones (por ejemplo la de Render o la de un túnel) y toca Guardar. Se guarda en este dispositivo, así que la misma app instalada desde GitHub Pages puede apuntar al servidor que quieras sin re-desplegar.

      Servidor en uso: http://localhost:3000

      Si no llegan las notificaciones push

      • Comprueba que el servidor en uso (sección 7) sea el correcto y esté encendido.
      • En local: cd server && npm run dev. En la nube, revisa el panel del host.
      • El servidor guarda las suscripciones en memoria: si se reinicia, vuelve a tocar la campana (o recarga la página, que reenvía sola la suscripción).
      • Las notificaciones de sincronización y guardado son locales y funcionan sin servidor, pero necesitan que hayas aceptado el permiso.
